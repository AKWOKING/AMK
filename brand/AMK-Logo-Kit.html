4 · Usage rules

  • Emblem meaning: the amber triangle = the AMK network (3 nodes, one apex) — growth; the ring = the web it connects to. Don't rotate, recolor, or add shadows.
  • Clear space: keep an empty margin around the lockup equal to the height of the "A" in AMK.
  • Minimum size: primary lockup 120 px wide (digital) / 30 mm (print). Square icon 48 px.
  • On photos: use the inverted (white) version only; never place the navy version over busy backgrounds.
  • Client separation: AMK navy/amber is agency-only. Client sites (Sasse, SAHISCOL, NHICHS…) each keep their own brand. The agency badge on client sites stays small, bottom-corner, monochrome.
  • Files: SVG = master (web, print). PNG = ready to send (WhatsApp, email). Keep both in agency/brand/. Green v1 archive: agency/brand/v1-green/.
