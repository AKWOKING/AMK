4 · Usage rules

  • Emblem meaning: the gold triangle = the AMK network (3 nodes, one apex) — growth; the ring = the web it connects to. Don't rotate, recolor, or add shadows.
  • Clear space: keep an empty margin around the lockup equal to the height of the "A" in AMK.
  • Minimum size: primary lockup 120 px wide (digital) / 30 mm (print). Square icon 48 px.
  • On photos: use the inverted (white) version only; never place the green version over busy backgrounds.
  • Files: SVG = master (web, print). PNG = ready to send (WhatsApp, email). Keep both in agency/brand/.
