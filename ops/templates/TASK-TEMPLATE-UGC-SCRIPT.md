# GABARIT DE TÂCHE — Script UGC IA (livrable récurrent)

> `ops/` créé le 02/10 (KB §9, pilier 3). Pour AMK, l'UGC IA = **script uniquement** (verrou King) : on
> écrit la vidéo, on ne fabrique pas de faux humain. Mois 1 : pas de visage dans l'UGC.

**Déclencheur :** semaine de cadence (DM OPTIQUE : 1 vidéo UGC IA/semaine).

**Rôles :** orchestrateur = script + specs · King = approbation avant tournage/génération.

**Entrées requises :**
1. L'angle daté et vérifié du client (jamais un générique).
2. Le verrou technique du client : DM OPTIQUE = 1080×1920 · 30 fps · SAR 1:1 · H.264.
3. La structure de référence (vidéo `kvYn7Yp6Z9c` : produit + échelle surréelle — on réutilise la
   STRUCTURE, pas les assets).
4. Le garde-fou conformité (KB §8.6) si produit de santé.

**Sous-tâches :**
1. Hook dans les 2 premières secondes, en une phrase, dans les mots du client.
2. Trois temps max : constat réel → preuve visible → CTA WhatsApp (chaîne pré-remplie).
3. **Interdits absolus :** visage humain en mois 1 · illustration IA du produit · claim médical ou
   conséquence nommée (« cataracte », « perte de vision »…) · concurrent nommé · remise.
4. Note de compliance en fin de script (ce que chaque phrase a le droit de dire).

**Heures estimées :** script 0,75 h · relecture conformité 0,25 h · specs de génération 0,25 h.

**Spec de sortie :** fichier `clients/<slug>/content/` : script .md + chaînes WhatsApp + specs techniques
verrouillées + note de compliance.

**Exception :** l'angle exige un visage ou une preuve qu'on n'a pas → pivoter sur ce qui est vrai
(horaires, catalogue, bouton WhatsApp), jamais combler avec du faux.

**Succès :** le script passe le garde-fou §8.6 sans une seule réécriture · le CTA est une chaîne
WhatsApp pré-remplie · rien ne part sans approbation King.
