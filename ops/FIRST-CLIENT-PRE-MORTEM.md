# FIRST-CLIENT PRE-MORTEM — DM OPTIQUE · 05/10 · à lire dans le taxi vers Bonabéri

> Chaque étape : les deux pannes les plus probables + le repli. Une ligne par panne. Si ça dévie,
> on ne négocie pas le prix, on protège la prochaine étape.

**1 · Accueil & revue du contrat.** Panne : il a des questions juridiques pointues → repli : le document
est « document de travail, non-juridique », on note la question, on y répond après, on ne bricole pas
le texte sur place. Panne : un proche non annoncé conteste → repli : VISIT-FALLBACKS scénario 5
(bienvenue, re-pitch 5 min, le close reste sur M. Domche).
**2 · Acompte & reçu.** Panne : pas de signal mobile-money sur place → repli : on sort de la pièce
2 minutes, jamais « on commencera quand même ». Panne : il veut un reçu papier immédiat → repli :
reçu manuscrit daté signé des deux + confirmation WhatsApp dans l'heure ; le proforma tamponné suit.
**3 · Démo du site.** Panne : pas d'internet au cabinet → repli : copie offline de v2.2 sur le
téléphone (chargée la veille — vérifier avant de partir). Panne : « c'est beau mais je veux autre
chose » → repli : mood board A/B **seulement s'il pousse sur le look** ; sinon « les ajustements
sont dans le mensuel, après la mise en ligne ».
**4 · Shooting photos.** Panne : lumière inutilisable → repli : on shoote ce qui est shootable
(montures, détails), on recale les 2 photos cabinet à S2 — C1 ne dépend d'aucune photo. Panne : il
n'a pas 30 minutes → repli : 8 photos prioritaires de la liste (entrée, salle, mains, monture), le
reste plus tard.
**5 · Session 8a.** Panne : il refuse le naming tier-1 → repli : ligne photographiée à 15 000 FCFA,
jamais une remise. Panne : il accepte sans comprendre → repli : on relit la clause à voix haute,
consentement écrit daté le jour même.
**6 · Close & prochain pas.** Panne : il ne signe pas → repli : VISIT-FALLBACKS scénario 1 (deal
ouvert, date précise, jamais partir sans engagement daté). Panne : il signe mais « appelle-moi pour
la suite » → repli : le prochain pas se fixe DANS la pièce (jour + heure du point S1).
**7 · Transition acompte → onboarding (jour même).** Panne : l'encaissement tarde à se confirmer →
repli : rien ne démarre avant confirmation (règle : encaissé, pas promis) ; on annonce la file
d'attente, pas le démarrage. Panne : il s'attend à tout voir le soir même → repli : le runsheet S1
est envoyé le jour même — la vitesse est dans le plan visible, pas dans l'improvisation.
**8 · Kickoff site (post-déclencheur).** Panne : Vercel/og capricieux au déploiement → repli :
drag-drop du dossier entier, test `test_dmoptic_page.mjs` AVANT de lever noindex (noindex en dernier).
Panne : il demande un changement avant publication → repli : mineur = fait ; structurel = « c'est le
rôle du mensuel, on publie la v2.2 testée 38/38 ».
**9 · FB/TikTok/GBP.** Panne : le code SMS GBP n'arrive pas → repli : carte postale en plan B, fiche
en préparation, jamais de fausse donnée publiée. Panne : il veut garder ses comptes personnels →
repli : comptes au nom du cabinet créés devant lui (ruling), accès AMK en admin — on ne prend pas
ses comptes, on en crée.
**10 · Publication C1 (16/10).** Panne : un chiffre/une heure est faux → repli : la checklist avant
poste (heures sans jours, pas de claim, pas de prix inventé) ; au doute, on retarde de 24 h, jamais
on corrige en public. Panne : zéro réaction → repli : rien — S1 mesure la mise en place, pas
l'audience ; on tient le calendrier.
**11 · Lancement pub W1-A.** Panne : zéro clic à 3 000 FCFA → repli : kill rule, on coupe, on
diagnostique avant de relancer (jamais « on rajoute 2 000 pour voir »). Panne : des messages
arrivent mais hors cible → repli : on répond quand même (c'est le cabinet qui répond), on ajuste le
ciblage, pas le message.
**12 · Première semaine retainer.** Panne : il écrit à toute heure et attend du live → repli : le
rythme Mon/Mer/Ven est annoncé dès S1 (retainer-rhythm.md) — cadrer tôt, pas après l'usure. Panne :
il veut « juste un petit ajout » hors scope → repli : la phrase : « c'est noté pour le point de
mercredi » — jamais un oui immédiat qui tue le rythme.
