# ONBOARDING — deux pistes, pas un gabarit

> Créé le 02/10 (ruling King, KB §9 — Wayfront). Un client retainer et un client projet ne s'onboardent
> pas avec le même template. Le mauvais playbook fait plus de dégâts que pas de playbook.

## Piste PROJET — exécuter vers un résultat défini
Clarté absolue sur quatre choses, écrites : **scope** (ce qui est livré, et ce qui ne l'est pas —
`CONDITIONS-D-INTERVENTION-*.md` sert de modèle : « non inclus » aussi explicite que « livré ») ·
**livrables** · **calendrier** · **définition de « fini »**.
Le client projet veut voir l'horizon rétrécir : jalons, paiements déclenchés par livraisons, clôture.
⚠️ Jouer le playbook retainer ici = cérémonies de partenariat qui noient le livrable = **scope creep**.

## Piste RETAINER — construire un partenariat long
Trois fondations : **vision** (où il veut être dans 12 mois, pas « plus de trafic ») · **rythme**
(cadence de publication, réunion/reporting mensuel, canal unique) · **valeur continue** (le reporting
montre la portée vers son WhatsApp, pas une liste de tâches — le client n'achète pas de la maintenance,
il achète de la portée).
⚠️ Jouer le playbook projet ici = le client se sent **transactionnel**, ligne de facture au lieu de
partenaire — il demandera le détail des tâches au lieu de regarder les chiffres.

## Le cas HYBRIDE — DM OPTIQUE
Pack Global = setup (projet) + 30 000 FCFA/mois (retainer). L'onboarding fait les deux, **dans l'ordre** :
- **La visite du 07/10 clôture le projet** : conditions posées, proforma, photos, calendrier de build.
- **Le mois 1 onboard le retainer** : cadence 2 publications/semaine, premier reporting, rythme WhatsApp.
- **Nommer la frontière**, à la livraison du setup, avec une phrase du type :
  *« Le setup est livré et payé. À partir de maintenant on travaille la portée : deux publications par
  semaine, le site vit, et on regarde les chiffres ensemble chaque mois. »*
  Le client doit **sentir** le basculement — sinon le retainer sera jugé comme un projet sans fin.

## Clôture (offboarding)
Le cabinet garde comptes, site, contenus **et nom de domaine** ; AMK rend les accès propres avec un
préavis d'un mois (conditions §5). Une sortie propre est un argument commercial.
