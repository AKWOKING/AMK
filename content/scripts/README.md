# AMK — CONTENT SCRIPTS

**Convention:** one file per script, numbered, with a status header.

```
# Video N — <slug>
Status: draft | approved | rendered | posted   ·  Updated: YYYY-MM-DD
Audience: …  ·  Source asset: …  ·  Funnel stage: …  ·  Expected outcome: …
Duration target: Ns  ·  Language: FR master + EN variant
Gates: [ ] 3-second hook (question/specific, ONE person, no self-intro)
       [ ] outcome-over-features (features are the minority of beats)
       [ ] "why should someone care?" answered per beat
       [ ] zero-fluff read-aloud pass
       [ ] clarity: what we do · who we help · which outcome · emotional journey start→middle→end
       [ ] one clear CTA (DM "PREVIEW" closing beat, separate from the payoff)
       [ ] no real clinic/school named without written permission (anonymise)
       [ ] 3-component pre-flight: script → visuals → voice
```

Then the beats: `HOOK (0-3s)` → `PROBLEM` → `DEMO (real website footage)` → `PAYOFF FRAME` → `CTA FRAME (DM PREVIEW)`.
Rules per beat: one message per beat · one question per screen when listing · every conclusion/CTA on its own clean mobile-readable frame · no overlays on the demonstrated UI · never animate the demonstrated UI (titles/labels may pop-in; match-and-move between beats allowed).

## Porte W43 — avant les portes ci-dessus, pour tout script CLIENT (ruling King, 21/10/2026)

Tout script destiné au compte d'un client (TikTok, Reels, Shorts, carrousel, légende issue d'un
contenu) porte, en tête de fichier, les **six cases du gabarit** — source :
`sales/research/2026-W43-techniques.md` **§12b** ; règle debout :
`content/strategy/CONTENT-STRATEGY-V2-2026-10-05.md`.

```
Porte W43 §12b — [ ] cas client d'abord · [ ] un seul axe · [ ] objet réel · [ ] preuve citée une fois
                 · [ ] sortie honnête · [ ] un seul CTA
```

Les portes de la maison restent **supérieures** en cas de conflit ; la porte W43 vient **avant**, au
moment d'écrire, parce qu'elle décide de qui parle en premier. Un script client sans les six cases est
un brouillon, pas un script.
