## 5 · Ce qui a été volontairement laissé dehors

| Écarté | Pourquoi |
|---|---|
| Tout prix, même « à partir de » | Verrou client explicite (21/10) |
| « Promo », « offre », « cadeau » | Idem — et l'image n'en contient aucun |
| Un nombre de montures disponibles | Ruling du 21/10 : on ne chiffre pas le stock, même quand c'est vrai |
| « Corrige la vue », « soigne » | Contrainte 3 du dossier — on décrit le geste, pas un résultat médical |
| Un témoignage, un avis, une note | Aucun avis réel à ce jour : rien ne s'invente |
| « Test gratuit » | Pratique dominante du marché, fermée chez nous — on ne s'aligne pas dessus |

**Les hashtags** : cinq, tous locaux ou catégoriels. Sur Facebook ils pèsent peu ; au-delà de six, ils donnent surtout l'impression d'une page qui remplit un formulaire. Ils sont là pour la recherche interne et pour la cohérence avec TikTok, pas pour la portée.

**L'heure** : en soirée, quand les parents sont rentrés. C'est une habitude de lecture, pas une donnée mesurée — à vérifier sur les premières publications plutôt qu'à supposer.
