## 4 · Comment reprendre une photo

L'historique les garde toutes, à l'octet près. Le commit **avant** le retrait est celui du 24/10 (`47597f91`), et les fichiers y sont à leur chemin d'origine :

```bash
# une photo précise
git show 47597f91:clients/dm-optic/photoshoot/femmes_1.1/PXL_20261016_123745403.jpg > /tmp/photo.jpg

# tout le dossier, d'un coup
git checkout 47597f91 -- clients/dm-optic/photoshoot/

# ou l'historique complet d'une frame
git log --oneline -- clients/dm-optic/photoshoot/femmes_1.1/
```

**Ce que cela change** : l'arbre de travail du dépôt passe de 560,1 Mo à **188,5 Mo** ; `.git` reste à ~1,06 Gio (l'historique n'est pas réécrit — c'est la décision séparée, `ops/AUDIT-FICHIERS-2026-10-24.md` §6 ②).

**Garde-fou** : `.gitignore` ignore désormais `photoshoot/*/PXL_*.jpg` (sauf les deux photos en production). Un prochain import de shooting ne reviendra pas tout seul dans le dépôt.
