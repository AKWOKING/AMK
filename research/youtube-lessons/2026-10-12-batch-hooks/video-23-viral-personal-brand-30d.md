## 3 · TOOL AUDIT — PRINCIPES, PAS OUTILS

Outils cités : ManyChat (payant — **rejeté**, et notre NO-CALL/WhatsApp-only rend le DM-automation
IG hors-sujet), Amazon page, IG/TikTok features natives (reels d'essai, vidéo-réponses). **Principes
extraits (4 stratégies) :**
1. **Dire différemment quelque chose de différent** — auditer l'espace : tout le monde dit « le
   marketing est le nouveau bouche-à-oreille » → elle a dit l'inverse. Le hook gagne quand la cible
   se dit « c'est exactement ce que je pensais ». Les avis clients/livres = mine d'or de formules.
2. **Montrer différemment quelque chose de différent** — signature visuelle reconnaissable son
   coupé (sa veste rouge) ; **être remarqué ≠ faire confiance** : confiance = même façon
   d'apparaître, répétée ; 3 audits (ma signature / mon confort durable / la pièce où est
   l'audience).
3. **Un fil conducteur + des « at bats »** — tester 3 messages × formats ; le test EST le plan ;
   ne pas surproduire (l'algo s'en fiche) ; « 30 jours pour se lever, 30 ans pour bâtir ».
4. **Un gagnant + du carburant** — message prouvé organiquement → mêmes assets vers les autres
   canaux ; le paid seulement après ; « c'est de la distribution ».
